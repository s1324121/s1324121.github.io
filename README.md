### 🛠 作品概要・技術的アプローチ
* **制作ツール**: Blender 
* **モデリング**: ローポリゴン（Low-poly）の世界観を意識し、キャラクターや背景の木々、大砲などをモデリング。
* **アニメーション**: ウサギが手前に走ってくる躍動感と、大砲を発射した瞬間のカメラの揺れ（スクリーンシェイク効果）を意識し、臨場感のあるカメラワークを実装しました。
* **エフェクト**: 爆発時の火花やパーティクル、ライティングによる明暗の変化を工夫し、迫力のある演出に仕上げています。

### 🎨 デザインの意図・UI/UXのこだわり
* **視覚的なヒエラルキー（情報設計）**
  ユーザーが上から下、左から右へと自然に目線を動かせるよう配置を工夫しました。まずインパクトのある「Face Necklace」というメインコピーに目を引かせ、中央で製品の具体的な特徴（顔文字の変化）を伝え、最後に右下のボタンへ誘導する動線にしています。
* **ターゲット層を意識した配色と視認性**
  新感覚のガジェットという先進的な世界観を伝えるため、ビビッドなピンクとパープルを基調にしました。文字にはフチ取りやドロップシャドウを適用し、スマホなどの小さな画面で見ても一瞬で文字が読めるよう「可読性」を重視しています。
* **コンバージョン（行動）を促すボタン設計**
  Webサイトやアプリで最も重要となる「詳しく見る▶︎」のボタン（CTA）を右下に配置。グラデーションと立体感をもたせることで、ユーザーが思わず「タップしたくなる」ようなUIデザインを意識しました。

---

### 💡 フロントエンドエンジニアとしての強み
私は、デザイナーが制作したデザインカンプの「余白（マージン）の意図」や「コンポーネントの配置理由」を高いレベルで理解し、再現性の高い実装ができるエンジニアを目指しています。
Photoshopを用いたビジュアル制作の経験を活かし、ただコードを書くだけでなく、ユーザーにとって心地よく、ビジネスの成果（クリック率や回遊率）に貢献できるフロントエンド開発に取り組みます。
