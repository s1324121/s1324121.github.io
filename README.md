# About

> Blenderで制作した、ピンクのうさぎが夜の森を進む3Dアニメーションです。ローポリゴンの世界観の中で、キャラクターの動きとカメラワークの連動にこだわりました。

## 概要

> 3Dアニメーションにおけるカメラワークと、キャラクターの動きを連動させる表現を学ぶために制作しました。少し不気味で怪しげな夜の森を、ピンクのうさぎが迷いながら進んでいくような、独特でミステリアスな世界観を目指しました。


## 主な機能

> * ピンクのうさぎキャラクターの3Dモデリング
> * キャラクターの歩行に合わせた、追従するカメラアニメーション
> * フリー素材の背景（森や道）を活用したステージのレイアウト
> * 怪しげな夜の雰囲気を引き立てる、紫の空と独特なライティング設定
> 
> 

## 使った技術

> * Blender（モデリング、アニメーション、カメラワーク、レンダリング）
> 
> 

## こだわった点・工夫したところ

> 一番苦労したのは、うさぎの移動に合わせたカメラワークの調整です。カメラがただ一定の速度で追うだけだと画面が退屈になってしまうため、うさぎの歩幅や上下の揺れ、進むスピードに合わせて、カメラの距離や角度を何度も微調整しました。
> 背景の森や道にはフリー素材を使用していますが、そのまま配置するのではなく、自分が表現したい「少し不気味でミステリアスな空気感」が出るように、ライトの色や当たる角度を工夫して全体のトーンを統一させました。

# About

架空のガジェット「Face Necklace」をプロモーションするためのWebバナー広告です。ターゲット層にひと目で商品の魅力とワクワク感が伝わるポップなデザインをPhotoshopで制作しました。

## 概要

> 「もしも相手の気持ちが形に見えたら面白いな」というアイデアから、架空のプロダクト『Face Necklace』を企画し、その魅力を伝えるためのWebバナー広告を制作しました。タイムラインやWebサイトの中でパッと目を引き、思わず「詳しく見る」をクリックしたくなるような、キャッチーで楽しいデザインを目指しました。

## アプリのURL

> こちらから実際に公開しているアプリをご覧いただけます：[URL]

## 主な機能

> * Photoshopを使用したWebバナー広告のデザイン・レイアウト
> * キャラクター（顔文字）やロゴなどのパーツ制作
> * スマートフォンでの閲覧を意識した文字の視認性・配置の最適化
> 
> 

## 使った技術

> * Adobe Photoshop
> 
>

## こだわった点・工夫したところ

> 一番こだわったのは、文字の読みやすさとポップな世界観の両立です。メインの「Face Necklace」というロゴは、ふちどりを二重にしたり立体感を少し出したりして、海外のおもちゃのような可愛さを意識しました。
> また、この商品の最大の売りである「感情に合わせて顔文字が変わる」という特徴がひと目で伝わるように、左下に3つの感情のバリエーション（怒り・照れ・悲しみ）を丸いアイコンにして並べました。背景のピンクと紫のコントラストが強すぎると文字がぼやけてしまうので、文字の後ろに白い座布団（吹き出し）を敷くなど、細かいレイアウトの調整に苦労しましたが、その分すっきりまとまったと思います。
